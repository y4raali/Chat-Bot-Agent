# Chat-Bot-Agent
The project's concept revolves around creating an interactive web application on the Hugging Face Spaces platform, allowing users to input a "Prompt" (instruction or question). The application sends this input to a ready-made language model (LLM) via an application programming interface (API), and then automatically receives and analyzes the response to determine whether the model correctly understood the context and the request.

Run code along with your own Huggingface API key to enter host server.
